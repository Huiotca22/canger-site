У каждой версии Minecraftсвоя папка с модами.

canger ставит Vanilla, Fabric, Forge и NeoForge из официальных источников, сам подбирает нужную Java и запускает игру с модами только той версии, которую вы выбрали. Профилей нет — есть версии.

Проблема

Ошибка «Incompatible mods found»
начинается с общей папки

Мод — это не файл, а обязательство: конкретная версия Minecraft, конкретный загрузчик, конкретный диапазон Java. Сложите такие обязательства в одну папку, и рано или поздно они столкнутся.

На диске

Игровой каталог — это сама версия

versions/<id> передаётся как --gameDir. Общие библиотеки и ресурсы лежат выше и не копируются в каждую папку.

.minecraft
  • %APPDATA%\.minecraft\общий корень
  • versions\<id>\JSON, JAR и natives этой версии
  • mods\моды только этой версии
  • saves\миры только этой версии
  • config\конфиги модов
  • options.txtнастройки графики и управления
  • libraries\общие библиотеки
  • assets\общие ресурсы
  • runtime\Java

Старые моды из общего .minecraft\mods автоматически не переносятся. Это намеренно: переносить значит смешивать. Скопируйте нужное вversions\<id>\mods руками — один раз.

Что поддерживается

Каталог собирается, а не зашит

Версии и сборки берутся из официальных manifest-файлов. Если Mojang или Forge выпустил релиз, он появится в лаунчере без обновления программы.

  • Vanilla

    релизы и снапшоты

    Полный список релизов и снапшотов Mojang, включая схему 26.x.

  • Fabric

    meta.fabricmc.net

    Одна последняя совместимая сборка на каждую версию Minecraft. Устанавливается в общий content root.

  • Forge

    1.13 и новее

    Автоматическая установка официальным installer: проверка SHA-1, запуск --installClient, валидация созданного профиля и родительского клиента. Рекомендуемая сборка приоритетнее последней.

  • NeoForge

    только стабильные

    Список берётся из официального maven-metadata.xml, installer сверяется по SHA-256, после установки проверяются id, inheritsFrom и main class.

  • Моды

    Modrinth

    Каталог Modrinth, установка файла по переданной контрольной сумме. Несовместимые с выбранной версией файлы отключаются до старта игры.

О сайте

Что стоит знать до установки

Нужно ли ставить Java вручную?

Нет. Нужный major версии скачивается с Adoptium и проверяется по SHA-256. Если подходящая Java уже есть в системе, используется она.

Что будет с моими модами из старой папки?

Ничего. Общая .minecraft\mods автоматически не переносится — так наборы разных версий не смешиваются. Скопируйте нужные файлы в versions\<id>\mods вручную.

Работает ли CurseForge?

Да, если задан API-ключ: через переменную окружения CANGER_CURSEFORGE_API_KEY или файл %APPDATA%\.minecraft\canger\settings.json. Меню для ввода ключа в приложении нет. Modrinth работает без ключа.

Почему окно такое маленькое — 700×400?

Это осознанное решение: лаунчер умещается рядом с игрой, а не занимает половину экрана. Окно намеренно нельзя растягивать и разворачивать.

Будет ли Linux или macOS?

Пока нет. В коде есть Unix-ветки для путей, classpath, natives и загрузки Java, но ни одна из них не собиралась и не запускалась. План кроссплатформы записан в README, ориентир — 0.2.0.

Почему установщики не подписаны?

Authenticode-сертификата нет. Пока его не будет, SmartScreen будет предупреждать. Сверяйте SHA-256 — значения есть в таблице выше и в заметках релиза.
