# canger-site

Лендинг лаунчера [canger](https://github.com/Huiotca22/Canger).

- Один самодостаточный `index.html`: CSS и JS внутри файла, зависимостей и сборки нет.
- Изображения лежат в `assets/` — это реальные скриншоты собранного `canger.exe` и знак приложения.
- Сайт публикуется через GitHub Pages.

## Локальный просмотр

```powershell
node server.js
```

Откройте <http://127.0.0.1:8899>.

## Правка

Всё содержимое страницы — в `index.html`. Скриншоты обновляются из
`C:\canver\site-assets\` после пересборки приложения.
